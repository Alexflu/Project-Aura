# Local assets required

No skeletal mesh, animation, map or MetaHuman binary is included in Git. Follow
`docs/skeleton-zero.md` from the repository root. The native mannequin stage needs
no authored map. Locally prepared Characters, Aura and assembled MetaHumans folders
are ignored, including shared Epic dependencies. Record asset source and license
before sharing any `.uasset` files. The repository's MIT license does not relicense
these assets.
